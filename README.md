# GloveCare

GloveCare is a carpal-tunnel rehabilitation system that turns a sensor glove into a guided, measurable exercise session. A wearable glove streams finger-touch and wrist-orientation data to a live web dashboard, where the patient follows one exercise at a time with clear instructions, audio cues, and automatic timing — while every movement is captured as structured data for analysis. The goal is simple: make home physiotherapy repeatable, trackable, and easy to follow for both patients and clinicians.

The hardware is built around an ESP8266 microcontroller reading five TTP223 capacitive touch sensors (one per fingertip) and an MPU6050 inertial measurement unit for pitch and roll. The firmware in `hardware/GloveCare_Glove.ino` samples the sensors continuously and exposes them over a local access point (`GloveCare-ESP8266`) or your own Wi-Fi, serving a JSON endpoint that the dashboard polls for live readings. Sensor data is delivered over USB serial at 115200 baud for the Python pipeline, so the same glove works equally well plugged into a laptop on a desk.

The dashboard (`dashboard.html`) is a compact, clinical control panel: a current-task strip shows the active exercise with start, skip, and view-sensor controls; sensor cards show live wrist, acceleration, gyroscope, and touch values; and progress panels track session time, completed exercises, and device status. Each session runs five exercises — Loose Fist, Fingertip Touching, Wrist Rotation, Finger Tapping, and Hand Wave — for exactly 20 seconds each, auto-advancing to the next exercise with an audio instruction and finishing on its own, so the user only has to follow along. There is no AI score on screen — just the effective state of the session, the timer, and the glove.

The `ai/` directory contains the machine-learning pipeline: `collect_data.py` records labeled sensor windows into `dataset/`, `preprocess.py` and `feature_extractor.py` turn raw streams into feature windows, and `train_model.py` trains a random-forest classifier (evaluated in `evaluate_model.py`, artifacts saved with joblib in `ai/model/`). To run the full stack, install the dependencies from `requirements.txt` (`pip install -r requirements.txt`), flash the glove, then start `python ai/dashboard_server.py` — it serves the dashboard along with a live `/api/sensor` endpoint and classifies the current exercise in real time, falling back to a static preview with "Waiting for Glove" when no hardware is connected.
